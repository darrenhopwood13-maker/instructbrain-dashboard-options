## Variant 2: Ledger

### Design stance
One idea per band, huge numerals, generous space. It is a page you could hand to a client.

### Key choices
- **Layout:** vertical bands, each answering a single question. No cards, no dashboard furniture.
- **Typography:** display-scale sans for the figures, with the prose written as sentences rather than
  labels. The headline is a statement ("Everything still open, at a glance"), not a title.
- **Colour:** navy and ink on warm paper. Laser Green appears **only as fills** - it fails contrast as
  text on light paper, so it is never used that way.
- **Interaction:** a period control (7 / 30 / 90 days / all time) that rescales every figure, a chart
  crosshair that reads out a week, and survey rows that expand to show the items inside.

### Trade-offs
- **Strong at:** being understood with zero training. It survives a client meeting and a board pack.
- **Weak at:** with thin data it can look empty rather than calm, and one project's problems hide
  inside an organisation-wide total.

### Best for
Client meetings and anything that gets read by someone who does not use the product daily.
